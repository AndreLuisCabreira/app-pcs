# Protótipo HTML/CSS para Figma

Esta pasta é uma cópia visual independente das telas JavaFX do IntraTech PC Builder. Nenhum arquivo `.java` foi alterado ou substituído.

## Como visualizar

Abra `index.html` em um navegador. Use o menu lateral para alternar entre as telas. A página de autenticação pode ser aberta pelo botão “Sair da conta”.

O protótipo usa somente HTML e CSS, inclusive para navegação, abas, tema claro/escuro e recolhimento do menu. Ele não acessa banco de dados e não executa as regras da aplicação Java.

## Como levar ao Figma

Use um plugin do Figma que importe uma página HTML ou URL, ou abra o arquivo no navegador e capture cada tela em 1280 × 800. Os endereços de cada tela terminam em:

- `#login`
- `#dashboard`
- `#componentes`
- `#importar`
- `#benchmarks`
- `#builds`
- `#analises`

As imagens usadas pelo protótipo ficam em `assets/` e foram copiadas dos recursos originais do aplicativo.
